# Picfair store assets

Upload files for store.armanparsa.earth, generated from the site's own
symbol (`NavInner.tsx`) and Lyon wordmark (`HeroNameSVG.tsx`), so the store
uses the exact same marks as armanparsa.earth. Not used by the website build.

| File | Use in Picfair |
|---|---|
| `logo-wordmark-light.svg` / `.png` | Header logo on the **dark** theme (recommended) |
| `logo-wordmark-dark.svg` / `.png` | Header logo if you choose the **light** theme |
| `logo-symbol-light.*` / `logo-symbol-dark.*` | Alternative minimal logo, as on the site nav |
| `watermark-symbol.png` | Custom watermark (subtle) |
| `watermark-wordmark.png` | Custom watermark (name, stronger) |

Colours: light = `#f8f4ef` (paper), dark = `#1c1814` (ink).
PNGs follow Picfair's limits (max 800px wide or 120px tall). Prefer the SVGs.
